
# Product Management and Purchasing Application

A C# application designed to manage product creation and purchasing through an interactive interface. This project demonstrates the fundamentals of C# application development, including object-oriented programming, product management, and purchase workflows.

## Features

- **Product Creation:** Create products by entering their relevant information.
- **Product Management:** View and manage available products.
- **Purchasing Workflow:** Select products and complete purchase operations.
- **User Interface:** Interact with the application through its interface.

## Usage

### Creating Products
1. Launch the application.
2. Navigate to the product creation section.
3. Enter the required product information.
4. Save the product.

### Purchasing Products
1. Browse the available products.
2. Select a product to purchase.
3. Follow the application's purchasing workflow.
